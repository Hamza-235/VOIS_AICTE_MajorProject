Netflix Data Analysis

Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Netflix's movies and TV shows dataset using Python. It explores content distribution, genres, ratings, release trends, directors, and country-wise availability to identify meaningful patterns and insights within Netflix's content library.

Objectives

- Analyse the distribution of Movies and TV Shows.
- Explore content trends across different years.
- Identify popular genres and content categories.
- Examine country-wise content distribution.
- Analyse ratings and content duration.
- Identify patterns through data visualization.

Technologies Used

- Python – Data analysis and processing
- Pandas – Data cleaning and manipulation
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization
- Jupyter Notebook – Interactive analysis

Dataset

The project uses a Netflix Movies and TV Shows dataset containing information such as:

- Show ID and Title
- Content Type (Movie or TV Show)
- Director and Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre (Listed In)
- Description

Project Workflow

1. Data Loading: Imported the Netflix dataset using Pandas.
2. Data Cleaning: Handled missing values and duplicate records.
3. Data Exploration: Examined dataset structure, columns and statistical summaries.
4. Exploratory Data Analysis: Investigated content types, release trends, ratings, genres and country distribution.
5. Data Visualization: Created charts and graphs using Matplotlib and Seaborn.
6. Insights: Identified patterns and trends in Netflix's content catalogue.

Key Analysis Areas

- Movies vs TV Shows distribution
- Content added over time
- Top content-producing countries
- Most common genres
- Distribution of content ratings
- Movie duration and TV show seasons
